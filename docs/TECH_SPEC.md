# Техническое задание — «Живой Учебник»

## 1. Общая информация
- Название: Живой Учебник  
- Тип: образовательный веб‑сайт / цифровая обучающая платформа  
- Цель документа: зафиксировать требования для проектирования, дизайна и разработки без двусмысленностей.

## 2. Цели и задачи
- Основная цель: интерактивная платформа для эффективного, наглядного и вовлекающего изучения материалов.
- Для пользователя: структурированные материалы; самопроверка тестами/интерактивами; отслеживание прогресса; повышение мотивации.
- Для бизнеса: привлечение и удержание; доверие к продукту; база пользователей для дальнейшего развития (премиум, масштабирование).

## 3. Целевая аудитория
- Основная: ученики и студенты 14–23, начинающие специалисты, пользователи с трудностями в классическом обучении.
- Характеристики: активные мобильные/desktop пользователи; предпочтение визуального и интерактивного контента; потребность в простых объяснениях сложных тем.

## 4. Функционал
- MVP: главная; каталог тем; страницы уроков (текст + визуал); интерактивные тесты/задания; отображение результатов; форма обратной связи.
- Расширенный (план): регистрация/авторизация; личный кабинет; сохранение прогресса; рекомендации; адаптация под уровень.
- Ключевые действия: выбрать тему → изучить материал → пройти тест → получить результат → вернуться с сохранённого места.

## 5. Контент
- Типы: текст; иллюстрации/схемы; видео (при наличии); интерактивы (квизы, тесты).
- Источник: контент нужно создавать; возможна адаптация имеющихся материалов; должен быть простой, структурированный, практико-ориентированный.

## 6. Визуальный стиль и UX/UI
- Брендбук: отсутствует, требуется разработка.
- Гамма/настроение: спокойная образовательная; дружелюбная, мотивирующая, технологичная; современный минималистичный дизайн; акцент на читаемости; адаптивность.
- Референсы: современные образовательные платформы и интерактивные лендинги с сильной типографикой (конкретные ссылки — при появлении).

## 7. Технические требования
- Технологии: React + TypeScript; Vite; Tailwind CSS; ESLint.
- Архитектура: компонентный подход; масштабируемость; готовность к интеграции backend.
- Интеграции: аналитика (GA/аналоги) опционально; платежи — не нужны на первом этапе.

## 8. Сроки и ресурсы
- Сроки: аналитика, дизайн, разработка MVP — уточняются.
- Ресурсы: команда 1–2 человека; бюджет — уточняется.

## 9. Открытые вопросы
- Финальный список учебных дисциплин.
- Формат и объём контента.
- Необходимость монетизации.
- Конкретные сроки релизов.
