# Задачи для Frontend-разработчика (Сайт)

**Ваша главная цель** — сделать красивый, понятный и работающий лендинг, который станет "визитной карточкой" проекта для жюри хакатона.

### 1. Настройка проекта
- [ ] Инициализировать проект на `Next.js` или `Vite + React` с `TypeScript`.
- [ ] Настроить `Tailwind CSS` для быстрой и адаптивной верстки.

### 2. Создание компонентов
- [ ] Создать отдельные React-компоненты для каждого обязательного блока с сайта: `ProblemSolution`, `Team`, `WhyOurTeam`, `Roadmap`, `TechImplementation`.

### 3. Верстка и стилизация
- [ ] Сверстать все секции лендинга, уделяя внимание дизайну и удобству восприятия (это 10% от итоговой оценки).
- [ ] Добавить плавные анимации появления блоков при скролле для лучшего впечатления.

### 4. Интеграция контента
- [ ] Вставить в компоненты весь текст, изображения и другие материалы, подготовленные Product & Content Lead.

### 5. Развертывание (Деплой)
- [ ] Развернуть сайт на `Vercel` или `Netlify`, чтобы получить публичную ссылку для сдачи проекта.
- [ ] Протестировать, что сайт корректно открывается на разных устройствах.
